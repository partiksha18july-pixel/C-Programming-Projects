## 📌 Introduction
The Quiz Application is a simple console-based program developed using the C programming language. It allows users to answer multiple-choice questions and tests their basic knowledge of C programming.

The application displays questions with four options, checks the selected answers and calculates the final score.

## 🎯 Project Objective
The main objective of this project is to understand and implement basic C programming concepts through an interactive quiz application.

## ✨ Features
- Displays multiple-choice questions.
- Provides four options for each question.
- Accepts answers from the user.
- Checks whether the selected answer is correct or incorrect.
- Calculates the final score.
- Displays a performance message based on the score.

## 🛠️ Technologies Used
- **Programming Language:** C
- **Compiler:** Programiz Online C Compiler
- **Header Files:** stdio.h

## 📚 C Concepts Used
This project demonstrates the following C programming concepts:

1. **Structures:** Used to store questions, options and correct answers.
2. **Arrays:** Used to store multiple questions and their options.
3. **Loops:** Used to display questions one by one.
4. **Conditional Statements:** Used to check answers and calculate results.
5. **Variables:** Used to store user choices and scores.
6. **Input and Output:** Used to interact with the user.

## ⚙️ How the Application Works
1. The application displays a welcome message.
2. A question with four options appears on the screen.
3. The user selects an answer (A, B, C or D).
4. The program checks the selected answer.
5. The score increases for every correct answer.
6. After all questions are completed, the final score is displayed.

## 💻 How to Run the Program
1. Open an online C compiler such as Programiz.
2. Copy the source code into the editor.
3. Click the Run button.
4. Answer the questions displayed on the screen.
5. View your final quiz score.

## 📊 Scoring System
- Each correct answer awards 1 point.
- Incorrect answers receive 0 points.
- The maximum score is 5 points.
